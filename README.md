# Portfólio — Matheus Junior Marques

Site pessoal apresentando minha trajetória como desenvolvedor, meus projetos, formação e stack.

## Acesse

- **Vercel:** https://matheus-marques.vercel.app
- **GitHub Pages:** https://matheus-marques-dev.github.io/Portfolio/

O deploy é automático: cada push no branch `main` atualiza os dois endereços.

## Sobre

Página única (one-page) com:

- **Hero** — nome em destaque e uma "linha de corrida" animada que segue o cursor
- **Sobre** — trajetória e formação (Etec e Fatec Franca)
- **Projetos** — Conciliador de Estoque, QuickBill, Catálogo de Filmes e Sistema Bancário, com prints, problema e solução e link para o site no ar
- **Experiência** — histórico profissional em e-commerce e marketplaces
- **Stack** — front-end, back-end e DevOps
- **Contato** — e-mail, currículo em PDF, LinkedIn e GitHub

Tema claro e escuro automáticos, layout responsivo e respeito a `prefers-reduced-motion`.

## Tecnologias

Arquivo único `index.html` com HTML, CSS e JavaScript puro sem frameworks, sem build step.

## Rodando localmente

Não há dependências nem build. Basta servir os arquivos estáticos:

```bash
# clone o repositório
git clone https://github.com/matheus-marques-dev/Portfolio.git
cd Portfolio

# sirva com qualquer servidor estático, por exemplo:
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.
